# 경매 입찰 계산기

입찰가를 넣으면 제비용·세금까지 빼고 순수이익과 수익률이 나오는 단독 계산기.

- 라이브: <https://claude.ai/code/artifact/b9993d72-190c-4cb5-a09d-c9f4fb8cb5cd>
- 파일: `index.html` **하나뿐**. 빌드 없음, 의존성 없음, 서버 없음.
  더블클릭해서 브라우저로 열어도 그대로 돌아간다.

## 산식

`geotuscan-clone`에서 원본 스냅샷을 역산해 확인한 식과 동일하다.
예시 값(감정가 9100 / 입찰가 5818 / 매도 9000 / 수리비 800 / 명도 0 / 기타 50 /
대출 80% / 4.5% / 5개월)을 넣으면 원본 결과 12개 항목이 그대로 나온다.

| 항목 | 산식 |
| --- | --- |
| 낙찰가율 | 입찰가 ÷ 감정가 |
| 취득세 | 입찰가 × 1.1% (빌라·도시형 자동) / 아파트는 직접 입력 |
| 중개비 | 매도예상가 × 0.7% |
| 이자 | 대출금 × 금리 × 개월/12 (대출금 = 입찰가 × 대출비율) |
| 총 제비용 | 취득세 + 중개비 + 이자 + 수리비 + 명도비 + 기타 |
| 예상 소득금액 | 매도예상가 − 입찰가 − 총 제비용 |
| 종합소득세 | 소득 × 기본세율 − 누진공제 (6~45%) |
| 지방소득세 | 종합소득세 × 10% |
| 순수이익 | 소득 − 종소세 − 지방세 |
| 실제 투자금 | 입찰가 − 대출금 + 총 제비용 |
| 수익률 | 순수이익 ÷ 실제 투자금 |

"목표 수익으로 입찰가 거꾸로 구하기"는 이분탐색이다. 입찰가가 오르면
순수이익이 단조 감소하므로 해가 하나다.

## 동작

- 금액 단위는 전부 **만원**
- 처음 열면 예시 값이 채워져 있고, 숫자를 건드리면 안내가 사라진다
- 입력값은 그 브라우저의 `localStorage`에만 남는다 (서버 전송 없음)
- 라이트/다크 둘 다 대응, 380px 폭까지 가로 스크롤 없음

## 고칠 곳

세율이나 요율은 `<script>` 맨 위 `BRACKETS` / `ACQ_RATE` / `BROKER_RATE`에 모여 있다.
