진헌스캔 이용안내

  1. 조건 걸기 — 왼쪽 상세 조건에서 지역·종류·가격·유찰·특수권리를 조합합니다. 상단 빠른칩으로 자주 쓰는 조건을 한 번에 넣을 수 있습니다.
  2. 결과 훑기 — 최저가율(감정가 대비 현재 최저가)이 낮을수록 유찰이 누적된 물건입니다. 정렬을 바꿔 가며 봅니다.
  3. 상세 확인 — 행을 누르면 기일 내역, 특수권리, 수익 계산기가 열립니다.
  4. 관심 저장 — ★ 를 누르면 이 브라우저에 저장됩니다(서버 전송 없음).
  5. 내보내기 — 엑셀(CSV) 버튼으로 현재 검색 결과 전체를 내려받습니다.

데이터에 대하여

현재 표시되는 물건은 기능 시연용 샘플입니다. 실제 법원경매 물건·주소·금액이 아니며, 입찰 판단에 사용하면 안 됩니다. 실제 물건은 법원경매정보(courtauction.go.kr)에서 확인하세요.

실데이터 연동

백엔드가 준비되면 api.js 의 CONFIG.mode 를 'remote' 로 바꾸고 endpoint 만 지정하면 화면 수정 없이 그대로 동작합니다.
